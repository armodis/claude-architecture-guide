# Universal Instructions (Layer 0)

These apply to **every** Claude Code session on this machine, in every domain.
Keep this file domain-neutral — anything specific to one domain belongs in that
domain's root CLAUDE.md (Layer 1), not here.

## Output style

- Prefer clear, direct prose. State the recommendation, then the reasoning.
- Use complexity ratings (Trivial / Low / Medium / High) rather than time estimates.

## Working habits

- Re-read a file immediately before acting on its contents, even if read earlier.
- For long-running commands, run them in the background and hand the prompt back.
- When staging for commit, list specific paths rather than `git add -A`.

## Safety

- Confirm before irreversible or outward-facing actions.
- Prefer moving files to a dated trash dir over deleting them.
